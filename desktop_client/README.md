# Max Messenger Desktop Client

Десктопный клиент для мессенджера Max на PyQt6.

---

## 📦 Установка

```bash
cd desktop_client
pip install -r requirements.txt
```

---

## 🚀 Запуск

```bash
python client.py
```

---

## 🔐 Авторизация

1. Введите номер телефона в формате `+79991234567`
2. Отсканируйте QR-код в приложении Max
3. QR-код сохраняется в `cache/qr_code.png`

---

## 📱 Возможности

### ✅ Реализовано:
- ✅ Авторизация по QR-коду
- ✅ Список чатов/диалогов
- ✅ Поиск по чатам
- ✅ Отправка текстовых сообщений
- ✅ Просмотр истории сообщений
- ✅ Отображение фото (превью + открытие в полном размере)
- ✅ Видеоплеер для видео внутри чата
- ✅ Отправка файлов (фото, видео, документы)
- ✅ Статус бар с информацией

### 🎨 UI/UX:
- Современный тёмный дизайн (Catppuccin-style)
- Поддержка Enter для отправки (Shift+Enter для новой строки)
- Прокрутка к новому сообщению
- Подсветка непрочитанных чатов

## 🎮 Управление

| Действие | Клавиша/Кнопка |
|----------|----------------|
| Отправить сообщение | `Enter` или кнопка `➤` |
| Новая строка | `Shift+Enter` |

| Поиск чатов | Поле поиска слева |

| Воспроизвести видео | Кнопка Play на плеере |

---

## 🖼️ Медиа

### Фото
- Отображаются как превью в чате
- Двойной клик → открытие в полном размере

### Видео
- Встроенный плеер прямо в сообщении
- Поддержка MP4, AVI, MKV, WebM

### Файлы
- Отправляются как документы
- Поддержка любых типов файлов

---

## ⚠️ Примечания

1. **Сессия сохраняется** в `cache/session.db` — повторная авторизация не требуется
2. **QR-код истекает** через ~30 секунд — будет сгенерирован новый
3. **Для закрытия** просто закройте окно — сессия сохранится

---

## 🐛 Известные ограничения

- Метод `send_file()` может отличаться в зависимости от версии PyMax
- Некоторые типы медиа могут не отображаться корректно
- Нет поддержки голосовых сообщений

## 🔧 Настройка

### Изменение темы
Откройте `client.py` и измените переменную `STYLESHEET`.

### Изменение размера окна
В `MainWindow.__init__()` измените:
```python
self.setMinimumSize(900, 600)  # Ширина, Высота
```

## 📞 Поддержка

При возникновении проблем:
1. Проверьте версию PyMax: `pip show maxapi-python`
2. Убедитесь, что QR-код отсканирован вовремя
3. Проверьте подключение к интернету
